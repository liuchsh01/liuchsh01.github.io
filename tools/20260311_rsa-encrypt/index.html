RSA ENCRYPTION

RSA 加密工具

输入 RSA 公钥和明文，在浏览器中生成 Base64 密文。公钥和明文不会上传到服务器。

纯 Base64 公钥会自动补全为标准 PEM 格式。

RSA 适合短文本；PKCS#1 v1.5 的明文上限为密钥字节数减 11。

快捷键：⌘ / Ctrl + Enter

BASE64 OUTPUT

加密结果

兼容与隐私说明

本工具使用项目内置的 JSEncrypt 3.3.2，在浏览器内执行 RSA PKCS#1 v1.5 加密，可与常见 Java RSA/ECB/PKCS1Padding 解密实现配合。你的公钥、明文和密文不会由本工具发送到网络。
