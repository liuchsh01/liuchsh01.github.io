格式与安全说明

MD5 与 SHA 系列会把文本按 UTF-8 字节计算；浏览器文本框中的换行以 LF 处理。逐行模式不包含换行符，会保留中间空行，但忽略末尾换行产生的额外空项。文件按原始二进制字节计算。

Java hashCode 复现 String.hashCode() 的 UTF-16、有符号 32 位整数结果，只适用于文本，切换到文件模式时会禁用。

MD5 与 SHA-1 已不适合密码保存、数字签名等抗碰撞安全场景；校验下载文件时请优先选择 SHA-256 或更强算法。
