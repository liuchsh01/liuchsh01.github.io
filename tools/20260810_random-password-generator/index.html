SECURE PASSWORDS

随机密码生成器

按字符类型、数量和长度批量生成随机密码。可指定必须包含或排除的字符，所有随机过程都在浏览器本地完成。

填写的每个字符都会在每个密码中至少出现一次
默认排除容易混淆的数字和字母，可自行修改
快捷键：⌘ / Ctrl + Enter

默认使用数字、小写和大写字母。
