    语法说明

    支持范围与执行规则

    支持 * 通配符、, 列表、- 范围、/ 步长，JAN–DEC、SUN–SAT 英文缩写，以及 @hourly、@daily、@weekly 等常用别名。星期中的 0 和 7 都表示周日；日期与星期同时受限时，按传统 Unix Cron 规则，任一条件匹配就会执行。

    未来时间使用浏览器当前时区计算，起算时间本身不计入结果。本工具不支持 Quartz Cron 的秒、年份、?、L、W 和 # 扩展语法。
