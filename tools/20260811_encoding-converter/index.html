编码解码工具

集中处理 Base64、URL 和 HTML 实体编码。支持中文与多行文本，所有内容仅在当前浏览器中转换。

UTF-8 文本 解码时兼容标准 Base64 与 Base64URL 字符。

使用说明

Base64 按 UTF-8 文本处理；URL 的“参数或路径片段”会编码保留字符，“完整网址”会保留协议、斜杠和查询结构；HTML 解码支持浏览器可识别的命名实体与数字实体。

HTML 实体解码只还原字符，不会对内容做安全过滤。需要放入网页时，仍应根据实际上下文进行转义和安全校验。
