处理说明

转换使用项目内置的固定版本 js-yaml 4.1.0 解析与生成 YAML。输入内容、转换结果和下载文件均只在当前浏览器中处理，不会上传。

YAML 锚点会在转为 JSON 时展开；循环引用无法表示为 JSON。超出 JavaScript 安全整数范围的数字可能损失精度，精确标识符建议使用字符串。
