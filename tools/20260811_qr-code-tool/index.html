依赖与隐私

所有内容均在浏览器本地处理

二维码生成使用锁定版本的 qrcode 1.5.4，图片识别使用 jsQR 1.4.0，两者通过 CDN 加载且不会接收你的文本或图片。首次打开页面需要联网加载组件；组件加载失败时，页面会明确提示对应功能不可用。

复杂背景、透视变形、低对比度或过小的二维码可能无法识别。生成时建议保持前景和背景有足够对比度，并为二维码四周保留空白。
