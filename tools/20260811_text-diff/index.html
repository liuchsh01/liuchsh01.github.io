使用说明

按行寻找最小差异，并对成对修改的行继续标出字符变化。“忽略空白差异”会合并连续空白并忽略行首尾空白；最多比较两侧合计 2,000 行、每侧 50 万字符。快捷键：⌘ / Ctrl + Enter。
