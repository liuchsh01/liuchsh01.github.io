JWT 支持 HS256/384/512、RS256/384/512、PS256/384/512 和 ES256/384/512 验签。JWE 支持 dir、RSA-OAEP、RSA-OAEP-256 搭配 A128/192/256GCM 解密。密钥、Token 和解析结果不会由本工具上传。
