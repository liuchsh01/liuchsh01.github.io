LOCAL PASSWORD HASHING

Bcrypt 生成与验证

生成带随机盐的密码 Hash，或检查密码是否与已有 Hash 匹配。所有计算在浏览器本地完成，密码不会上传或保存。

格式与使用说明

Hash 共 60 个字符，包含版本、cost、盐和摘要。同一密码每次生成的 Hash 通常不同，应使用“验证密码”判断匹配，不能直接比较两次生成的字符串。生成使用浏览器安全随机数；验证无需手动填写盐或 cost。

超过 72 个 UTF-8 字节的密码会被拒绝，避免 Bcrypt 截断后出现相同前缀被判定为匹配的情况。中文和 Emoji 通常占多个字节；本工具不会修剪或规范化密码，也不会自动进行预哈希。空密码和旧系统特殊预处理不在本工具支持范围内。

为控制浏览器计算耗时，本工具将 cost 限制在 4–16；无法在后台计算时，最高为 12 且需要等待完成。该上限是工具限制，cost 选择应结合实际用途和设备性能评估。实现依据：bcryptjs 官方文档；依赖已固定版本并保存在本地。
