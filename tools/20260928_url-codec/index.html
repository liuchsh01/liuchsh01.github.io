选择处理规则，输入内容后点击“URL 编码”或“URL 解码”。

如何选择处理规则？

参数或路径片段：适合搜索词、单个参数值或路径的一段，会编码 / ? & = # + 等保留字符。使用浏览器的 encodeURIComponent / decodeURIComponent 规则，! ' ( ) * 等字符保持不变。

完整网址：保留协议、路径和查询分隔符，使用 encodeURI / decodeURI 规则；解码时 %2F、%3F 等保留字符的编码也会保留。若整个网址都被编码，请选择“参数或路径片段”解码。这里仅做字符转换，不解析或校验网址。

表单参数：处理单个参数名或参数值，不拆分查询串。按 application/x-www-form-urlencoded 规则把空格编码为 +，把原有 + 编码为 %2B；解码时先把 + 还原为空格。

三种模式解码时均严格检查百分号编码与 UTF-8，非法输入会报错；表单解码不会像部分服务端那样忽略错误或替换损坏字符。再次编码会将 % 变为 %25；多层编码可用“结果作为输入”逐次处理。规则依据：ECMAScript URI 处理、WHATWG 表单编码。
